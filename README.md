# 云绘生图 yunhui-image-gen

SillyTavern 第三方扩展 —— 通过 OpenAI 兼容 API 生图，支持标签触发与自动生图两种模式。

## 功能

### 模式 1：标签生图
- 在消息中用 `<yunhui>提示词</yunhui>` 标签触发生图
- 支持自定义生图尺寸、模型、负面提示词
- 支持 LoRA 加载

### 模式 2：自动生图
- 每条 AI 回复自动总结剧情 + 生成生图提示词 + 生图
- 基于角色卡 + Horae 状态保持人物/服饰一致性
- 三层上下文：按天快照（总结层）+ 最近 N 条对话（短期层）+ 当前消息（生图依据）
- 多张图片卡片：左右翻页 / 竖排平铺 / 网格 三种展示形态
- 内置提示词工程（7 步结构 / 元素三层 / 描写范围控制 / 第一人称视角）
- 支持手动总结（自动总结失效时的兜底）
- 删除图片只删图不删提示词（出现占位，可随时重新生成）
- 支持 ComfyUI 桥接（云绘/MoeBridge）或任意 OpenAI 兼容 API

## 安装

### 方式 A：在线安装（推荐）
SillyTavern → 顶栏扩展图标 → 扩展管理 → 安装扩展 → 输入：
```
YunLin000/yunhui-image-gen
```
刷新页面后在扩展列表启用「云绘生图」。

### 方式 B：手动放置
将本仓库文件放入：
```
SillyTavern/public/scripts/extensions/third-party/yunhui-image-gen/
```
刷新页面后启用。

## 配置

1. 打开扩展设置 → 点击「打开云绘生图面板」
2. **云绘地址**：填 OpenAI 兼容 API 的 base URL（如 `http://127.0.0.1:8080/v1`）
3. **API Key**：如需鉴权则填写（云绘本地通常留空）
4. **生图模型**：点刷新按钮拉取可用模型
5. 自动生图 Tab：配置辅助 LLM（用于总结剧情 + 写生图提示词）

## 要求
- SillyTavern ≥ 1.12.0
- 一个 OpenAI 兼容的生图 API（ComfyUI 桥接 / 云绘 / 其他）
